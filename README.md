# بقالة العزي للمواد الغذائية

## الهدف
إعادة بناء تطبيق محاسبي/إدارة متجر Android أصلي مستند إلى دراسة التطبيق المرجعي المرفوع، مع الحفاظ على نطاق وظائفه وشاشاته وإعداداته، وتكييف الهوية والبيانات لبقالة العزي.

## المرجع الذي تمت دراسته
- الحزمة المرجعية: `com.kh.kh.sanadat`
- عدد ملفات الأرشيف: 5169
- DEX: 5 ملفات
- مكونات التطبيق الرئيسية المستخرجة من DEX: أكثر من 60 مكوناً.
- توجد موارد تخطيط كثيرة منها: الفواتير، الحسابات، المنتجات، التقارير، الإعدادات، الطباعة، النسخ الاحتياطي، الحوالات، العروض، المخازن.

## نطاق التنفيذ
- الفواتير والمبيعات والمشتريات والمرتجعات.
- العملاء والحسابات والحركات والأرصدة.
- المنتجات والمخزون والمخازن والتحويلات بين المخازن.
- العملات والأسعار.
- العروض والطلبات.
- الحوالات.
- التنبيهات والرسائل.
- التقارير.
- الطباعة الحرارية وBluetooth/ESC-POS والمشاركة.
- النسخ الاحتياطي والاستعادة وGoogle Drive.
- إعدادات الفواتير والطباعة والرسائل والمعلومات.
- RTL عربي وهوية بقالة العزي.

## قاعدة مهمة
لا تعتبر أي شاشة مكتملة بمجرد وجود XML أو زر تنقل. كل شاشة يجب أن تربط بمنطق البيانات والعمليات والتقارير والطباعة والمشاركة المناسبة لها، ثم تمر باختبار البناء والوظيفة.
